Pedido de prueba

Crea una solicitud simple sin procesar pagos reales

Selecciona el producto, la cantidad y tus datos básicos. El servidor calculará el total con el precio real almacenado en la base de datos.

  • El pedido se guarda en PostgreSQL.
  • El stock se descuenta después del envío.
  • El campo comentario también puede usarse como dirección.
  • Si necesitas varios productos, usa el carrito de compras.
